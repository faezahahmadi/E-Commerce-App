 🛒 Product Store App (React)

A modern Product Store application built with React that demonstrates state management using **Context API, Redux Toolkit, and React Query**.


---

## 🚀 Features

### 🧠 State Management
- Context API + useReducer
  - Theme toggle (Dark / Light mode)
  - Layout switch (Grid / List view)
  - Category selection (filter system)

- **Redux Toolkit**
  - Add to cart functionality
  - Remove items from cart
  - Increase / decrease quantity
  - Cart total price calculation
  - Cart item count tracking

- **React Query**
  - Fetch products from API
  - Fetch single product by ID (Product Details Page)
  - Loading and error states
  - Cached API data for better performance
